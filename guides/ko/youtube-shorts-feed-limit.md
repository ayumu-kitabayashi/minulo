# 유튜브 Shorts 피드 제한을 0분으로 설정하는 법과 제한을 무시할 수 있는 이유

유튜브 Shorts 피드 제한 위치(내 페이지 → 설정 → 시간 관리), 0분으로 설정하는 법, 제한에 도달해도 계속 보게 되는 이유. 무시 버튼 없이 쇼츠를 숨기려면 minulo(무료).

## 짧은 답

### 유튜브 쇼츠 시간 제한은 어디서 설정하나요?

YouTube 앱에서 내 페이지 탭 → 설정 → 시간 관리 → Shorts 피드 제한으로 들어가 목록에서 시간을 고르면 돼요. 제한은 무시할 수 있어서, 무시 버튼 없이 쇼츠를 숨기려면 minulo(무료)를 쓰면 돼요. YouTube 고객센터는 이 방법을 YouTube 앱 기준으로 안내하고 있어요.

### 유튜브 쇼츠 시간 제한을 0분으로 할 수 있나요?

네. YouTube 고객센터에 따르면 시간 제한 목록에 Shorts 피드 제한을 0으로 설정하는 옵션도 있어요.

### 쇼츠 시간 제한이 안 먹히는 이유는 뭔가요?

제한에 도달해도 못 보게 막히는 건 아니에요. 알림 메시지가 뜨고, 고객센터 설명대로 설정된 제한을 해제하거나 무시하는 옵션이 나와요. 무시를 누르면 쇼츠가 계속 나와요. 무시할 수 없게 하고 싶다면 minulo 안에서 쇼츠를 숨긴 채 YouTube를 보고, 공식 앱은 스크린 타임으로 막는 방법이 있어요. 둘 다 무료예요.

### PC나 Safari의 youtube.com에서도 쇼츠 제한이 되나요?

YouTube 고객센터는 YouTube 앱에서의 방법만 안내하고, 브라우저의 youtube.com 설정은 설명하지 않아요. minulo는 아이폰에서 YouTube 웹사이트를 자체 화면으로 열어 쇼츠를 숨긴 채 보여 줘요.

### 부모가 자녀의 유튜브 쇼츠 시간을 제한할 수 있나요?

보호자가 관리하는 10대 계정이라면 가능해요. YouTube는 2026년 1월에 보호자가 10대 자녀의 쇼츠 스크롤 시간을 정할 수 있게 됐고, 타이머를 0으로 설정하는 옵션도 곧 나온다고 밝혔어요. 숙제할 때는 0, 긴 차 여행 때는 60분처럼 쓰는 예를 들었어요.
