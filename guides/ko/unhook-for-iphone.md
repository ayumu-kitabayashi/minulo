# Unhook 아이폰 버전 있나요? 유튜브 추천, 쇼츠, 댓글 숨기는 법 (2026)

Unhook는 Chrome, Firefox, Edge용 브라우저 확장이고 스토어 설명에 Safari나 아이폰 이야기는 없어요. 아이폰에서는 minulo로 유튜브 쇼츠, 추천, 댓글을 무료로 숨길 수 있어요.

## 짧은 답

### Unhook 아이폰 앱이 있나요?

Unhook 확장 프로그램 사이트에 있는 건 Chrome, Firefox, Edge용이고, Chrome 웹 스토어 설명에는 Safari나 아이폰 이야기가 없어요. App Store에 Be Timeful Inc의 'Unhook:'이 있지만 같은 개발사인지는 확인하지 못했어요. 아이폰에서는 minulo로 유튜브 쇼츠, 홈 추천, 댓글을 숨길 수 있고 숨기기는 무료예요.

### Unhook는 아이폰 Safari에서 되나요?

공식 사이트와 Chrome 웹 스토어 설명 어디에도 Safari 이야기는 없어요. 휴대폰은 안드로이드 Firefox에서 모바일 유튜브에 쓸 수 있다고만 적혀 있어요.

### 아이폰에서 유튜브 추천을 숨기려면요?

minulo에서 유튜브를 열고 홈 추천이나 검색창 외의 홈을 켜요. 유튜브 자체로는, Google 도움말에 따르면 시청 기록을 삭제하고 사용 중지하면 홈에 맞춤 동영상이 표시되지 않아요.

### 아이폰에서 유튜브 댓글을 숨길 수 있나요?

minulo 안에서는 돼요. 댓글은 유튜브에서 숨길 수 있는 항목 중 하나이고 무료예요. YouTube 고객센터의 댓글 설정은 자기 영상을 관리하는 크리에이터용이에요.

### minulo를 쓰면 공식 유튜브 앱도 바뀌나요?

아니요. 쇼츠와 추천이 숨겨지는 건 minulo 안에서 유튜브를 열었을 때뿐이에요. 공식 앱을 안 열게 하려면 minulo 차단 탭에서 잠가요. 한 번에 2시간까지 무료예요.

### minulo는 무료인가요?

쇼츠, 홈 추천, 댓글 숨기기는 무료이고 시간 제한도 없어요. 일정, 2시간보다 긴 차단, 하드 모드는 minulo Pro예요.
