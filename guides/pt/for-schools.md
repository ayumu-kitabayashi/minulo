# Quando a lição de casa vira uma hora de Reels: minulo para professores, escolas e apoio ao estudante (iPhone)

Abriu o celular para a lição e passou uma hora nos Reels. O minulo é um app grátis para iPhone que oculta só os Reels, os Shorts e o Para Você do TikTok.

## Respostas curtas

### É grátis?

Sim. Ocultar os Reels, os Shorts e o Para Você do TikTok é grátis. Bloquear os apps oficiais também é grátis, até 2 horas por vez, e dá para começar de novo quantas vezes quiser. Bloqueios mais longos e agendamentos fazem parte do minulo Pro.

### E no Android?

Por enquanto o minulo é só para iPhone. Uma versão para Android está em preparação.

### Quais dados dos alunos são coletados?

Não há conta, e nomes e endereços de e-mail não são coletados. As páginas vistas e o que é digitado não são enviados. Só são enviados dados de uso anônimos, para melhorar o app.

### Uma turma ou grupo inteiro pode testar junto?

Escreva para workflowai.japan@gmail.com com o número de pessoas e o uso pretendido, e podemos conversar sobre como testar o Pro.
