# 仕事中にスマホでSNSを見てしまうときの対策

仕事中、ついスマホでインスタやショートを見てしまう。起きやすい場面、仕事の時間だけ SNS を静かにする集中モードとスクリーンタイムの設定、仕事でインスタを使う人の方法。

## 短い答え

### 仕事中にスマホを見てしまうのをやめるには？

勤務時間だけフィードを遠くします。SNS の通知を止めて SNS のないホーム画面に切り替える集中モード「仕事」を使い、SNS にスクリーンタイムの制限をかけ、スマホは手の届かないところに置きます。仕事でインスタを使うなら、アプリごと止めるのではなく、リールと発見だけを消します。

### 集中モードの「仕事」でアプリは止まりますか？

止まりません。集中モードは通知を許可するアプリとホーム画面のページを切り替えるだけで、アプリは開けます。開かないようにするなら、スクリーンタイムの「アプリ使用時間の制限」か「休止時間」でブロックをオンにします。

### 仕事中についスマホを触ってしまうのはなぜですか？

多くは短いすき間のせいです。返事待ち、読み込み待ち、始めたくない作業の前。スマホが手の届くところにあり、リールやショートは1〜2分を埋めるように作られています。スマホを離し、SNS の通知を止めると、きっかけの多くがなくなります。

### 仕事でインスタを使うけど、リールを見てしまうときは？

フィードのない形で使います。iPhone の minulo なら、リール・発見・おすすめ投稿を消した状態でインスタを開け、投稿・コメント・DM はそのまま使えます。消すのは無料です。ストーリーズの投稿や通話は公式アプリが必要です。

### 勤務時間だけ SNS をブロックできますか？

できます。勤務時間にスクリーンタイムの「休止時間」や「アプリ使用時間の制限」を設定するか、minulo のブロック（1回2時間まで無料）を使います。曜日と時間で自動で切り替わる予定は minulo Pro の機能です。
