# minulo は安全？見えるもの・見えないもの・できないこと（2026年）

minuloは安全？アカウントはなく、SNSのパスワードはInstagramやYouTubeに直接送られminuloは受け取りません。送るのは匿名の利用状況だけ。スクリーンタイムで見えるもの、データの消し方、できないことまで。

## 短い答え

### minulo は安全ですか？

minulo にはアカウントがなく、SNS の ID やパスワードを受け取りません。ログインはアプリの中に表示した各SNSのサイトで直接行い、通信は minulo のサーバーを通りません。送るのは匿名の利用状況とエラーの内容だけで、あなたではなくアプリが作る無作為な番号と結びつきます。記録は iPhone の中だけにあり、アプリを削除すれば消えます。ただし「友だちに紹介」の紹介コードと合言葉、以前から無料でお使いの方の印は、iPhone のキーチェーンに残ります。

### minulo はあやしいアプリではありませんか？

App Store で配信しているアプリで（販売元：ayumu kitabayashi）、作っているのは北海道の個人事業「リリーフノート」（2025年7月開業・代表 北林 歩）です。リールやショートを消す機能は無料です。2026年9月に出たばかりなので、評価の数はまだ少なめです。

### minulo にインスタのパスワードを見られませんか？

見られません。パスワードは minulo の中に表示した Instagram のログインページで入力し、そのまま Instagram に送られます。minulo が ID やパスワードを受け取ること、保存すること、送ることはありません。ログイン状態を保つ Cookie は iOS が minulo 用に分けた場所に保存され、ほかのアプリや開発者からは読めません。

### minulo は個人情報を集めたり追跡したりしますか？

集めるのは、匿名の利用状況（ブロックを入れた、どのSNSで引き返した、言語と地域の設定、iOS の版など）、URL や名前を消したエラーの内容、App Store の検索広告から来たかどうかです。名前・メールアドレス・位置情報・広告識別子は取らず、他社のアプリやサイトをまたいだ追跡もしません。App Store の表示も「ユーザに関連付けられないデータ」だけです。

### スクリーンタイムで止めたアプリは minulo に知られますか？

知られません。Apple はプライバシーを守るため、選んだアプリを中身の分からない印にして渡します。minulo はその印を iPhone の中に保存してスクリーンタイムに渡すだけで、どのアプリなのかは分かりません。
