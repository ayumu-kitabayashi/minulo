# minulo のよくある質問

minuloのよくある質問。SNSはそのまま使い、リール・ショート動画・おすすめ投稿だけを消すiPhoneアプリについて、1つずつ答えます。

## 短い答え

### インスタのリールだけ消して、友だちとのDMは使えますか？

はい、使えます。minulo の中で Instagram を開くと、リールと発見のタブ、おすすめの投稿が表示されない状態になります。DM、友だちの投稿、自分の投稿、プロフィールはそのまま使えます。消すものは1つずつ選べて、この非表示の機能は無料です。

### インスタをDMとグループDMだけで使えますか？

使えます。インスタの「DM以外のタブ」をオンにすると、DMとお知らせだけが残り、リール・発見・ホームのフィード・おすすめ投稿は消えます（TikTok にも同じ設定があります）。minulo を使っている人の多くは、クラスのグループDMのためにインスタを残している学生です。

### YouTubeのショートだけ消して、ふつうの動画は見られますか？

はい、できます。minulo の中で YouTube を開くと、ホームのショートの棚とショートのタブが表示されなくなります。検索、登録チャンネル、ふつうの長さの動画はそのまま見られます。ショート動画を非表示にする機能は無料です。

### いつものインスタやTikTokのアイコンを押すと、どうなりますか？

minulo は、iPhone のスクリーンタイムの仕組みを使って、選んだ公式アプリを開けないようにできます。開こうとすると「ブロック中です」という画面が出て、「minulo で開く」のボタンから minulo に移れます。止めるアプリを選ぶのも、ブロックを入れるのも無料です。

### インスタとYouTubeのほかに、どのSNSのおすすめを消せますか？

minulo は10のサービスに対応しています。Instagram、YouTube、TikTok、X、Threads、Facebook、Pinterest、Reddit、LinkedIn、Snapchat です。サービスごとに、リール、ショート、おすすめの投稿、発見のタブなど、消すものを1つずつ選べます。

### インスタのパスワードを minulo に教えることになりますか？

minulo に ID やパスワードを渡すことはありません。ログインは、各 SNS が用意している公式のログインページで直接行います。minulo が ID、パスワード、DM の中身を取得したり保存したりすることはなく、記録はすべて iPhone の中だけに保存されます。

### 友だちがDMで送ってきたリールは、見られますか？

DM で送られてきたリールやショートを開くと、縦に続く動画の流れに入る前に、minulo がいったん止めます。どうしても見たいときは「5分だけ開く」を押すと、5分間だけ見られます。5分たつと、自動でまた止まります。

### リールを消すのは無料ですか？ Proにすると何が増えますか？

リール、ショート動画、おすすめ投稿の非表示と、公式アプリのブロックは無料です。無料のブロックは1回2時間までで、明けたら何度でも入れ直せます。minulo Pro では、曜日や時間帯で自動で切り替わる予定、2時間を超えるブロック、解除に手間をかけるハードモード、minulo の中でも SNS を開かない「SNS を完全に止める」、複数のブロックリストが使えます。料金は月額1,480円、年額6,800円（7日間の無料体験つき）、または買い切り23,800円です。

### 仕事でインスタに投稿していても使えますか？

使えます。写真つきの投稿、コメント、DM への返信は minulo の中でも行えます。ストーリーズの投稿、ボイスメッセージ、通話は各 SNS のウェブ版に無いため使えませんが、「休憩する」を押すと、選んだ時間だけ公式アプリを開けます。

### FeedMinusとminuloは同じアプリですか？

はい、同じアプリです。FeedMinus は2026年9月に名前を minulo に変えました。App Store のページ、機能、無料で使える範囲は変わっていません。以前の名前で入れた人も、アップデートすればそのまま minulo として使えます。

### 日本語以外でも使えますか？ Androidはありますか？

minulo は iPhone 向けのアプリで、日本語、英語、韓国語、繁体字中国語、ドイツ語、フランス語、スペイン語、ポルトガル語、イタリア語、インドネシア語、タイ語、ベトナム語、ロシア語の13言語で使えます。言語は、アプリの「プロフィール」→「設定」→「言語」で選べます。Android 版は今のところありません。Android 版はテスト中で、順番待ちに登録すると公開のときに1通だけお知らせします。

### SocialLiteとminuloは何が違いますか？

どちらも、リールやショートを消して DM は残し、iPhone のスクリーンタイムで公式アプリを止めて自分のアプリに案内できます。評価の数は SocialLite がずっと多く、米国で15,412件です（2026年10月26日時点）。minulo は、SocialLite の App Store のページに名前のない TikTok・Threads・Pinterest・LinkedIn にも対応し、Chrome の拡張機能もあります。リール・ショート・おすすめ投稿を消す機能は無料です。minulo は2026年9月に公開したばかりの新しいアプリです。

### YouTubeでショートの上限を0にできるのに、minuloは要りますか？

YouTube をアプリだけで使い、上限が出たら自分でやめられるなら、YouTube のショートのフィードの上限で足りるかもしれません。ただ、大人のアカウントでは上限の表示を閉じられ、youtube.com やほかのSNSには効きません。minulo は自前の画面でショートを消し、Instagram・TikTok などほか9つのSNSにも対応し、公式アプリを止めることもできます。

### Opalとminuloは何が違いますか？

Opal はアプリ全体を止めるので、Instagram を止めている間は DM も使えません。minulo はリール・ショート・おすすめ投稿だけを消すので、DM や友だちの投稿は使えます。どちらも iPhone のスクリーンタイムでアプリを止めますが、minulo は閉じた扉の代わりに、リールの消えた minulo の画面へ案内します。
