# 旅行中に SNS を休んで、地図と連絡は使う方法（iPhone・2026年）

オフラインマップを入れ、インスタと TikTok を Wi-Fi だけにし、休止時間で地図と LINE を許可します。minulo ならフィードを無料で消して DM は使えます。

## 短い答え

### 旅行中に SNS を休んで、連絡だけは取るには？

minulo でフィードを消せば無料で DM は使え、公式アプリも1回2時間まで無料で止められます。iPhone の機能なら、休止時間で LINE と地図のアプリを［常に許可］に入れれば、それだけが使えます。

### 旅行中、通信なしで地図を使える？

マップならオフラインマップを出かける前にダウンロードしておけば使えます。Apple によると、一部の国や地域では使えません。

### 海外でインスタにデータを使わせないには？

［設定］→［モバイル通信］で、アプリの一覧のインスタをオフにします。Apple によると、そのアプリは Wi-Fi だけを使うようになります。

### データローミングはオフにしたほうがいい？

Apple は、旅行中はデータローミングをオフにすればローミングの請求を避けられると書いています。海外ではすべてのアプリでモバイルデータ通信が使えなくなるので、Wi-Fi・海外用のプラン・旅行用 eSIM を用意します。

### 休止時間中もメッセージは届く？

Apple によると、休止時間中は許可した通話・メッセージ・アプリだけが使えます。使うメッセージアプリを［常に許可］に入れておきます。

### minulo はオフラインで使える？

使えません。minulo は各 SNS のウェブ版をアプリの中で開くので、ウェブ版と同じく Wi-Fi かモバイルデータ通信が要ります。
