# TikTok の制限モードでできること・できないこと（iPhone・2026年）

TikTok の制限モードは成人向けなどの動画を絞り、「フォロー中」フィードと LIVE を使えなくします。「おすすめ」は消えません。設定方法と、おすすめを消したいときの方法。

## 短い答え

### TikTok の制限モードで「おすすめ」は消える？

消えません。制限モードは表示される動画の一部を除く機能で、「おすすめ」はそのまま使えます。TikTok のヘルプで使えなくなる機能として挙げられているのは、「フォロー中」フィードや LIVE でのギフトなどです。

### TikTok の「フォロー中」が消えたのはなぜ？

制限モードがオンなら、それが理由です。TikTok のヘルプに、制限モードでは「フォロー中」フィードを利用できないとあります。［設定とプライバシー］›［コンテンツ設定］›［制限モード］で、パスコードを入れてオフにします。

### 制限モードでは何が見えなくなる？

一部の人に不快な可能性があると TikTok が判断した動画です。下品な内容、性的な内容、リアルな暴力、不適切な環境での武器、薬物、成人向けのテーマへの明示的な言及などが挙げられています。判断は自動化システムと人間のモデレーターが行います。

### 制限モードはアカウントごとにオンにする？

はい。TikTok のヘルプによると、アカウントを複数持っている場合は、それぞれ個別にオンにする必要があります。

### TikTok の「おすすめ」を消すには？

TikTok に消す設定はありません。minulo で TikTok を開けば、「おすすめ」・見つける・投稿が消え、メッセージと「フォロー中」はそのまま使えます。無料です。
