# 推し活で X・インスタ・YouTube を推しの投稿だけにする方法（iPhone・2026年）

X はリストとミュート、インスタは［お気に入り］、YouTube は［登録チャンネル］で推しを追えます。minulo で開けば、X のおすすめ、インスタのリールと発見、YouTube のショートが消えます（消すのは無料）。

## 短い答え

### X で推しの投稿だけ見るには？

X のリストに推しを入れ、そのリストをホームに固定します。リストは作るときに非公開にもできます。［フォロー中］のまま閉じれば、次も［フォロー中］から開きます。［おすすめ］タブ自体を消したいなら、minulo で X を開けば無料で消えます。

### ライブのネタバレを X で見ないようにするには？

［ミュートするキーワード］に公演名やハッシュタグを入れ、ホームと通知のどちらか、または両方を選びます。期間は24時間・7日・30日・無期限から選べます。X のヘルプによると、ミュートした言葉も検索には出ます。

### インスタで推しの投稿だけ見るには？

推しを［お気に入り］に入れ、フィードの左上の［Instagram］から［お気に入り］を選びます。50件まで入れられ、新しい順に出ます。リールのタブと発見タブは残るので、そこを消すなら minulo を使います。

### minulo でショートを消すと推しのショートも消える？

minulo の中では、ショートの棚とショートのタブが消えます。ショートのリンクはふつうの再生画面で開くので、推しが共有したショートを1本ずつ見ることはできます。ショートのタブで続けて見たいときは公式の YouTube アプリを使います。

### 推しの DM やコメントは使える？

minulo の中のインスタと X で、DM やコメントは使えます。ストーリーズの投稿・音声メッセージ・通話は使えません。
