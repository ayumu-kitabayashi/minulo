# iPhoneでYouTubeのショートだけ消す方法：ふつうの動画は残す（すべての方法・2026年）

iPhoneでYouTubeのショートだけを非表示にする方法。公式はショートのフィード上限を0に。閉じても戻れない方法なら、minuloとスクリーンタイムを使います。

## 短い答え

### iPhoneでYouTubeのショートだけ消す方法は？

ショートの上限を0分にするだけでは足りません。大人のアカウントでは知らせを閉じるか上限を無視して見続けられ、登録チャンネルや送られてきたリンクのショートは残り、YouTube のヘルプが説明しているのはショートのフィードだけで、ホームのショートの棚や検索は対象として書かれていません。ショートだけ本当に消してふつうの動画を残すなら、minulo（無料）の中で YouTube を開きます。minulo を入れ、ホームの「サービスを追加」から YouTube を選び、YouTube の横の歯車で［ショートの棚を非表示］・［下のショートタブを非表示］・［ショートを普通の再生画面で開く］をオンにします。ふつうの動画・検索・登録チャンネル・後で見るはそのまま使えます。公式の YouTube アプリも止めたいなら、「ブロック」タブでスクリーンタイムで止めます（1回2時間まで無料）。

### ショートの上限を0分にすれば、ショートは全部消える？

全部は消えません。YouTube のヘルプが上限の対象として書いているのは「ショート フィード」だけです。上限に達しても、「ショート フィードを閉じるか、設定した上限を無視するか」を選ぶ知らせが出るだけです。2026年4月の報道では、0分にしても登録チャンネルのフィードにはショートが残り、検索にも出ることがあり、リンクから開いた1本のショートは再生されました。Engadget が伝えたアプリの表示も、スクロールは止まるが1本ずつのショートは見られる、という内容です。minulo は YouTube を minulo の中で開き、［ショートの棚を非表示］［下のショートタブを非表示］［ショートを普通の再生画面で開く］で、ショートの棚とタブそのものを消します。ショートを消す機能は無料です。

### YouTubeのショートを完全に非表示にできる？

大人のアカウントでは、YouTube アプリの中だけで完全には非表示にできません。minulo の中で YouTube を開けば、ショートは無料で消え、ふつうの動画は見られます。YouTube アプリでショートのフィードの上限を 0 にすると、上限に達したときに知らせが出ますが、ヘルプによると、ショート フィードを閉じるか、上限を無視して見続けられます。報道によると、登録チャンネルのショートは残り、リンクから開いた1本のショートも再生されます。

### ショートの上限は、Safari の youtube.com でも効く？

YouTube のヘルプでは、ショートのフィードの上限は YouTube アプリの機能として説明されています。youtube.com でショートを消したい場合は、Safari や自前のブラウザで動く Nope や minulo のようなアプリが使えます。

### つい YouTube アプリを開いてしまうのを止めるには？

iPhone のスクリーンタイムで YouTube アプリ全体を止められます。minulo も同じスクリーンタイムの仕組みを使いますが、YouTube を開こうとすると minulo に案内し、そこではショートが消えたまま、ふつうの動画は見られます。

### ショートのフィードの上限を 0 分にする手順

YouTube アプリの［マイページ］タブから［設定］→［時間管理］→［ショート フィードの上限］と進み、0 を選びます。YouTube の広報は2026年4月に The Verge に、0 分はすべての人に順に広げていると話しました（9to5Google が報道）。上限に達すると、ショート フィードを閉じるか、上限を無視して見続けられます。

### どのアプリも、公式の YouTube アプリからショートを消せないのはなぜ？

iPhone では、あるアプリがほかのアプリの画面を書き換えられないためです。ショートを消すアプリは、YouTube のウェブ版を自前の画面や Safari で開いてショートを隠し、スクリーンタイムで公式アプリを止める、という方法をとります。

### 勉強中に、講義の動画だけ見てショートは見ないようにするには？

YouTube アプリ全体を止めると勉強の動画まで見られなくなるので、ショートのフィードの上限を 0 にするか、ショートを消すアプリでふつうの動画と検索だけを使います。勉強の時間だけ止めたいときは、スクリーンタイムの休止時間や集中モードと組み合わせます。

### 子どもの YouTube のショートを止めたいときは？

保護者が見守りの設定をした10代のアカウントなら、保護者がショートを見る時間に上限をかけられ、0 にもできます。
