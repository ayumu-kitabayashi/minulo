# iPhoneでYouTubeのショートだけ消す方法：ふつうの動画は残す（すべての方法・2026年）

iPhoneでYouTubeのショートだけを非表示にする方法。公式はショートのフィード上限を0に。閉じても戻れない方法なら、minuloとスクリーンタイムを使います。

## 短い答え

### iPhoneでYouTubeのショートだけ消す方法は？

ショートの上限を0分にするだけでは足りません。大人のアカウントでは閉じて見続けられ、登録チャンネルや送られてきたリンクのショートは残り、YouTube のヘルプが説明しているのはショートのフィードだけで、ホームのショートの棚や検索は対象として書かれていません。ショートだけ本当に消してふつうの動画を残すなら、minulo（無料）の中で YouTube を開きます。minulo を入れ、ホームの「サービスを追加」から YouTube を選び、YouTube の横の歯車で［ショートの棚を非表示］・［下のショートタブを非表示］・［ショートを普通の再生画面で開く］をオンにします。ふつうの動画・検索・登録チャンネル・後で見るはそのまま使えます。公式の YouTube アプリも止めたいなら、「ブロック」タブでスクリーンタイムで止めます（1回2時間まで無料）。

### ショートの上限を0分にすれば、ショートは消える？

完全には消えません。0分にするとショートのフィードで上限の画面が出ますが、YouTube のヘルプによると、そこで上限を閉じるか無視するかを選べて、そのまま見続けられます。ヘルプが説明しているのはショートのフィードだけで、ホームのショートの棚が消えるとは書いていません。登録チャンネルや送られてきたリンクのショートも残ります。ホームの棚の × は、記事によると30日で戻ります。minulo なら、ショートの棚とタブは自分で設定を変えるまで消えたままで、無料です。

### YouTubeのショートを完全に非表示にできる？

大人のアカウントでは、YouTube アプリの中だけで完全には非表示にできません。minulo の中で YouTube を開けば、ショートは無料で消え、ふつうの動画は見られます。YouTube アプリでショートのフィードの上限を 0 にすると、上限のあとはショートのフィードが止まりますが、大人は上限の表示を閉じられます。登録チャンネルや送られてきたリンクのショートも残ります。

### ショートの上限は、Safari の youtube.com でも効く？

YouTube のヘルプでは、ショートのフィードの上限は YouTube アプリの機能として説明されています。youtube.com でショートを消したい場合は、Safari や自前のブラウザで動く Nope や minulo のようなアプリが使えます。

### つい YouTube アプリを開いてしまうのを止めるには？

iPhone のスクリーンタイムで YouTube アプリ全体を止められます。minulo も同じスクリーンタイムの仕組みを使いますが、YouTube を開こうとすると minulo に案内し、そこではショートが消えたまま、ふつうの動画は見られます。

### ショートのフィードの上限を 0 分にする手順

YouTube アプリのプロフィール（英語では You）から設定に入り、時間の管理（Time management）のショートのフィードの上限（Shorts feed limit）で 0 分を選びます。2026年4月から大人のアカウントでも 0 分を選べます。上限のあとの案内は、大人のアカウントでは閉じられます。

### どのアプリも、公式の YouTube アプリからショートを消せないのはなぜ？

iPhone では、あるアプリがほかのアプリの画面を書き換えられないためです。ショートを消すアプリは、YouTube のウェブ版を自前の画面や Safari で開いてショートを隠し、スクリーンタイムで公式アプリを止める、という方法をとります。

### 勉強中に、講義の動画だけ見てショートは見ないようにするには？

YouTube アプリ全体を止めると勉強の動画まで見られなくなるので、ショートのフィードの上限を 0 にするか、ショートを消すアプリでふつうの動画と検索だけを使います。勉強の時間だけ止めたいときは、スクリーンタイムの休止時間や集中モードと組み合わせます。

### 子どもの YouTube のショートを止めたいときは？

保護者が見守りの設定をした10代のアカウントなら、保護者がショートを見る時間に上限をかけられ、0 にもできます。
