# インスタをDMだけで使う方法（iPhone・2026年）：グループDMは残して、リールとフィードを消す

インスタには「DMだけ」のモードがなく、スクリーンタイムで止めるとDMも止まります。minulo の無料の「DM以外のタブ」で、グループDMは残してリール・発見・フィードを消す方法。

## 短い答え

### インスタをDMだけで使う方法は？（iPhone）

minulo の中でインスタを開き、無料の「DM以外のタブ」をオンにします。リール・発見・ホームのフィード・おすすめ投稿が消え、DM はグループDMも含めてそのまま使えます。いつもの癖で公式のインスタを開いてしまうなら、minulo にスクリーンタイムで公式アプリを止めてもらいます（1回2時間まで無料）。アイコンを押すと「ブロック中です」の画面が出て、「minulo で開く」から DM だけのインスタに移れます。インスタ自体には「DMだけ」のモードはなく、スクリーンタイムはアプリごと止めるので DM も使えなくなります。

### インスタをメッセージ専用にできる？

minulo ならできます。インスタの「DM以外のタブ」は無料で、残るのは DM とお知らせのタブだけです。DM だけの表示があるほかのアプリでは、その表示はたいてい有料です。UNDOOMED の Messages Only は公式サイトでは Pro、Stillfeed の DM だけの表示は Pro、Reelmute は Premium です。

### インスタに「DMだけ」のモードはある？

見つけられませんでした。代わりに minulo の無料の「DM以外のタブ」をオンにすると、DM だけが残ったインスタを開けます。インスタ自体では、大人のアカウントでもフォロー中のフィードへの切り替えや利用時間のお知らせはできますが、リールのタブと発見は残ります。minulo のようなアプリは、インスタのウェブ版の上に DM だけの画面を作ります。

### グループDMは使える？

使えます。グループDMもインスタの DM の一部なので、minulo の DM だけの画面でそのまま読めて送れます。

### 公式のインスタを消す必要はある？

ありません。minulo はスクリーンタイムで公式アプリを止め、アイコンを押したときに DM だけのインスタへ案内できます。

### 通知はどうなる？

通知は公式のインスタのアプリから届きます。公式アプリを止めていなければ通知はいつもどおり届き、返信は minulo でできます。minulo がスクリーンタイムで公式アプリをブロックしている間は、そのアプリの通知も届きません（iOS の仕組みです）。グループDMの通知を待っている日は、公式アプリを止めずに使ってください。

### 友だちから DM で届いたリールを開くとどうなる？

minulo の中では、DM から開いたリールは、縦に流れるフィードが始まる前で止まります。見たいときは「5分だけ開く」を押すと5分間だけ見られて、5分たつと自動でまた止まります。インスタのアプリだと、チャットから開いたリールはリールの画面で再生され、上にスワイプすればそのまま次々に流れます。返事をしようと開いたら、もう次のリールを見ていた、ということが起きにくくなります。DM で届いた YouTube のショートも同じです。

### グループDMの通知が多すぎるときは？

グループDMは、minulo の DM の画面でそのまま読めて送れます。1つのグループだけ通知が多いなら、インスタのアプリでそのチャットを開き、上の名前をタップして［ミュート］から［メッセージをミュート］をオンにします。ミュートしたことは相手に通知されません。クラスや部活の連絡が LINE ではなくインスタのグループDMにあると、インスタごと消すわけにはいきません。止めるのはリールのほうで十分です。

### インスタの通知を DM だけにするには？

インスタのアプリで［プロフィール］から右上の［メニュー］を押し、［お知らせ］を開きます。［プッシュ通知を一時停止］の下にある通知の種類のうち、メッセージ以外を1つずつオフにして、メッセージはオンのままにします。種類ごとの正確な名前は、インスタのヘルプでは確かめられませんでした。iPhone の［設定］→［通知］で、Instagram の［通知を許可］がオンになっているかも見ておきます。minulo からは通知を出しません。minulo が公式アプリをブロックしている間は、公式アプリの通知も届きません。

### DM だけにしても、ストーリーズは見られる？

「DM以外のタブ」をオンにすると、使えるのは DM とお知らせだけです。友だちのストーリーズも見たいなら、「DM以外のタブ」はオフのままにして、［リールと発見タブ］と［おすすめの投稿］をオンにします。リール・発見・おすすめ投稿は消え、ストーリーズはフィードの上に残り、DM もそのまま使えます。ストーリーズの投稿は、インスタのウェブ版に無いので minulo からはできません。

### インスタの「フォロー中」やおすすめの一時休止ではだめ？

知らない人の投稿を減らすだけなら、インスタの設定でもできます。フィードの左上の［Instagram］を押して［フォロー中］を選ぶと、フォローしている人の投稿とリールが新しい順に並び、おすすめ投稿は出ません。ただ、この選択は残らないので、次に開くとふつうのフィードに戻ります。投稿の［オプション］から［興味なし］を選ぶと、ふつうのフィードのおすすめ投稿を30日間止められますが、30日たつと戻り、リールと発見は対象外です。どちらを使っても、リールのタブと発見は画面に残ります。

### パソコンでインスタの DM は使える？

使えます。ブラウザで instagram.com を開いてログインし、左の［メッセージ］をクリックします。インスタの公式サイト（About Instagram）は、［作成］を押して相手を選び、［チャット］から［送信］する手順を説明しています。ただし、ウェブ版にもリールと発見のタブがあるので、パソコンに移っただけでは DM だけにはなりません。パソコンのウェブ版でどのメッセージ機能が使えるかは、インスタのヘルプで確かめられませんでした。

### minulo でできないことは？

リールが消えるのは minulo の中だけで、公式アプリそのものは変わりません。音声メッセージ・通話・ストーリーズの投稿は、インスタのウェブ版に無いので使えません。minulo が公式アプリを止めている間は、そのアプリの通知は届かず、minulo が代わりに通知を送ることもありません。minulo は iPhone のアプリで、Safari と Chrome で使える Mac 版もあります。Android 版はありません。くわしくは minulo にできないことへ。
