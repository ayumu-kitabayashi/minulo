# インスタに出るスレッズ（Threads）の投稿を消す方法（iPhone・2026年）

インスタのフィードに出る Threads の投稿を止める設定はありません。1件ずつ非表示にする、フォロー中にする、フィードなしで開く方法。

## 短い答え

### インスタのフィードに Threads の投稿が出るのはなぜ？

Meta が Threads の投稿を Instagram と Facebook に直接出しているからです。2023年11月に Instagram の責任者アダム・モセリ氏が、Threads の投稿をより多くの人に届けるための機能として発表しました。フォローしていない人の投稿も出ます。

### インスタに出る Threads の投稿を完全にオフにできる？

2026年10月の時点で、Instagram のヘルプにはその設定が見つかりませんでした。Threads の投稿を「…」から1件ずつ非表示にするか、フォローしている人だけが出る［フォロー中］に切り替えます。インスタは主に DM で使うなら、minulo でフィードをまるごと消して開けます。無料です。

### Threads の「他のアプリでのおすすめ」をオフにすれば、インスタに出なくなる？

自分に見える投稿は変わりません。この設定は、自分の Threads の投稿が Instagram と Facebook でおすすめされるかどうかを決めるものです。ほかの人の Threads の投稿は、これまでどおり自分のフィードに出ることがあります。

### ［フォロー中］にすれば Threads の投稿は消える？

［フォロー中］にはフォローしている人の投稿だけが、おすすめなしで出るので、ほかの人の Threads の投稿がおすすめとして出ることはありません。ただ、開き直すとふつうのフィードに戻るので、毎回選び直します。

### インスタに来る Threads の通知を止めるには？

Guiding Tech によると、Instagram の通知タブで Threads の通知を左にスワイプし、「…」から「このような通知をオフにする」を選びます。Instagram のヘルプではこの手順は見つかりませんでした。
