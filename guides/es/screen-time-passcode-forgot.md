# ¿Has olvidado el código de Tiempo de uso que pusiste tú mismo? Los pasos oficiales de Apple (iPhone, 2026)

¿Olvidaste el código de Tiempo de uso que pusiste en tu propio iPhone? Los pasos de Apple: Ajustes, Tiempo de uso, Cambiar el código y después tu cuenta de Apple.

## Respuestas cortas

### ¿Qué hago si he olvidado el código de Tiempo de uso?

Abre Ajustes, toca Tiempo de uso, luego Gestionar Tiempo de Uso, y toca dos veces Cambiar el código de «Tiempo de uso». Si se te pide, introduce el correo y la contraseña de la cuenta de Apple que usaste para configurar el código, y después introduce dos veces un código nuevo.

### ¿Puedo restablecer el código de Tiempo de uso sin mi cuenta de Apple?

La página de Apple solo describe cómo restablecerlo con la cuenta de Apple que introdujiste para la Recuperación del código de Tiempo de Uso. No da otra forma para tu propio dispositivo. Para otros casos, la página enlaza al soporte de Apple.

### ¿Por qué mi cuenta de Apple no sirve para restablecer el código de Tiempo de uso?

Necesitas la misma cuenta de Apple que usaste al configurar el código. Apple dice que puede ser distinta de la que tienes iniciada en el iPhone, o la de un familiar si estás en En Familia.

### ¿El código de Tiempo de uso es el mismo que el código del iPhone?

No. Apple dice que el código de Tiempo de uso no es el que usas para desbloquear el dispositivo. Solo sirve para cambiar ajustes, límites y restricciones de Tiempo de uso.

### ¿Puede minulo restablecer mi código de Tiempo de uso?

No. minulo no puede verlo ni restablecerlo. Usa los pasos de Apple en Ajustes, Tiempo de uso, Gestionar Tiempo de Uso, Cambiar el código de «Tiempo de uso».
