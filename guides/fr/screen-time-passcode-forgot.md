# Vous avez oublié le code Temps d’écran que vous avez défini vous-même ? Les étapes officielles d’Apple (iPhone, 2026)

Vous avez oublié le code Temps d’écran défini sur votre propre iPhone ? Les étapes d’Apple : Réglages, Temps d’écran, Modifier le code, puis votre compte Apple.

## Réponses courtes

### Que faire si j’ai oublié mon code de Temps d’écran ?

Ouvrez Réglages, touchez Temps d’écran, puis Gérer le temps d’écran, et touchez deux fois Modifier le code de « Temps d’écran ». Si on vous le demande, saisissez l’adresse e-mail et le mot de passe du compte Apple utilisés pour configurer le code, puis saisissez deux fois un nouveau code.

### Peut-on réinitialiser le code de Temps d’écran sans son compte Apple ?

La page d’Apple ne décrit que la réinitialisation avec le compte Apple saisi pour le code de secours pour Temps d’écran. Elle ne donne pas d’autre moyen pour votre propre appareil. Pour les autres cas, la page renvoie vers l’assistance Apple.

### Pourquoi mon compte Apple ne fonctionne-t-il pas pour réinitialiser le code de Temps d’écran ?

Il faut le même compte Apple que celui utilisé pour configurer le code de Temps d’écran. Apple indique qu’il peut être différent de celui connecté sur votre iPhone, ou être celui d’un membre de la famille si vous utilisez le partage familial.

### Le code de Temps d’écran est-il le même que le code de mon iPhone ?

Non. Apple indique que le code de Temps d’écran n’est pas le code de déverrouillage de votre appareil. Il sert uniquement à modifier les réglages, limites et restrictions de Temps d’écran.

### minulo peut-il réinitialiser mon code de Temps d’écran ?

Non. minulo ne peut ni le voir ni le réinitialiser. Suivez les étapes d’Apple dans Réglages, Temps d’écran, Gérer le temps d’écran, Modifier le code de « Temps d’écran ».
