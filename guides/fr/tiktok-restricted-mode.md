# Ce que fait le mode restreint de TikTok, et ce qu’il ne fait pas (iPhone, 2026)

Le mode restreint filtre les contenus pour adultes sur TikTok et désactive le fil Abonnements et les LIVE. Il ne retire pas Pour toi. Comment l’activer, et quoi utiliser à la place.

## Réponses courtes

### Le mode restreint de TikTok désactive-t-il la page Pour toi ?

Non. Le mode restreint filtre certains contenus de ce que TikTok affiche, mais Pour toi continue de fonctionner. L’aide de TikTok cite le fil Abonnements, les LIVE et les cadeaux en LIVE comme les fonctionnalités qui deviennent indisponibles.

### Pourquoi mon fil Abonnements a-t-il disparu sur TikTok ?

Si le mode restreint est activé, c’est normal. L’aide de TikTok indique que le fil Abonnements est indisponible en mode restreint. Désactivez-le dans Paramètres et confidentialité › Préférences de contenu › Mode restreint, avec votre code.

### Que bloque le mode restreint de TikTok ?

Les contenus que TikTok juge ne pas convenir à tout le monde, comme la vulgarité, les contenus à caractère sexuel suggestif, la violence réaliste, les armes dans un cadre inapproprié, les drogues et les références explicites à des thèmes adultes. TikTok s’appuie sur des systèmes automatisés et des modérateurs humains.

### Faut-il activer le mode restreint sur chaque compte ?

Oui. TikTok indique que si vous avez plusieurs comptes, vous devez activer le mode restreint sur chacun séparément.

### Comment se débarrasser de Pour toi sur TikTok ?

TikTok n’a aucun réglage qui le retire. Dans minulo, TikTok s’ouvre gratuitement avec Pour toi, Explorer et Créer masqués, tandis que les messages et Abonnements continuent de fonctionner.
