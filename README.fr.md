# minulo — masquer les Reels Instagram et les Shorts YouTube sur iPhone, en gardant les messages

[English](README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Português](README.pt.md)

**minulo** est une app iPhone qui retire uniquement les fils sans fin des réseaux sociaux (Reels, Explorer et publications suggérées d'Instagram, Shorts de YouTube, « Pour toi » de TikTok). Les messages et les groupes, la recherche, vos publications et celles des comptes suivis restent utilisables.

- App Store : https://apps.apple.com/fr/app/id6809352229
- Site : https://minulo.app/fr/
- Prix : masquer Reels, Shorts et recommandations est gratuit. minulo Pro est facultatif.
- Réseaux : Instagram, YouTube, TikTok, X, Threads, Facebook, Pinterest, Reddit, LinkedIn, Snapchat
- Développée par une seule personne. La plupart des utilisateurs sont lycéens et étudiants.

## Comment ça marche

1. minulo ouvre le site officiel de chaque réseau dans l'app et masque les parties choisies (onglet Reels, Explorer, Shorts, « Pour toi », publications suggérées).
2. Avec Temps d'écran, minulo peut bloquer les apps officielles. En touchant l'icône habituelle, un écran « bloqué » apparaît, et le bouton « Ouvrir dans minulo » mène à la version sans Reels. Inutile de supprimer les apps officielles.
3. La connexion se fait sur la page de connexion de chaque réseau. minulo ne reçoit ni n'enregistre votre mot de passe.

## Questions fréquentes

**Puis-je utiliser Instagram seulement pour les messages ?**
Oui. Activez « Tous les onglets sauf les messages » pour Instagram (même réglage pour TikTok).

**Une app peut-elle retirer les Reels dans l'app Instagram officielle ?**
Non : sur iPhone, une app ne peut pas modifier ce qu'affiche une autre app. minulo masque les Reels dans sa propre vue et, avec Temps d'écran, renvoie l'icône Instagram vers cette vue.

**C'est gratuit ?**
Masquer Reels, Shorts, « Pour toi » et les publications suggérées est gratuit.
